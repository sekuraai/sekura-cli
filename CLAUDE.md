## No comments in code (hard rule)

New and edited code must not contain comments, in any language or file type: no `//` or `/* */` in TS/JS, no `#` in shell, TOML, YAML or Python, no `--` in SQL, no `<!-- -->` in HTML or templates. No explanatory comments, JSDoc, TODO/FIXME notes, section dividers or commented-out code. Express intent through names, types and small functions. Leave existing comments as they are.

This rule overrides any skill, agent file, charter or doc in this repository that asks for comments.
